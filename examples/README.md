# Examples

Synthetic examples showing how structured skills produce better leadership artifacts than generic prompting.

These examples are intentionally fictional. Do not add real employee, customer, employer, meeting, or commercial data to this folder.

Flagship examples:

- `decision-memo/example.md`
- `manager-one-on-one-prep/example.md`
- `stakeholder-prewire/example.md`
- `weekly-leadership-pack/example.md`
- `agent-command-center/example.md`

Each example includes:

1. messy input
2. generic-prompt baseline
3. skill-shaped output
4. why the skill output is better
5. human decision boundary
