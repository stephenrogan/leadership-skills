# Generic Prompt vs Structured Skill

A generic prompt usually asks for advice.

A structured skill forces an operating shape:

| Generic prompt | Structured skill |
|---|---|
| Gives broad advice | Produces a named artifact |
| Blurs facts and interpretation | Separates evidence, hypothesis, confidence, and missing context |
| Often hides uncertainty | Labels assumptions and gaps |
| May overstep sensitive boundaries | Stops at human approval points |
| Ends with suggestions | Ends with owner, date, success signal, and follow-up loop |

The useful difference is not prettier writing. It is less decision drift.
