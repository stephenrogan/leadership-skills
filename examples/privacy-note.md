# Privacy Note

All examples in this repository are synthetic.

Do not contribute examples, evals, issues, or pull requests containing:

- real employee names or performance details
- real customer names or account details

- credentials, tokens, or secrets

If you want to use these skills on real work, keep the sensitive context inside your private agent client and do not commit it to this repository.
