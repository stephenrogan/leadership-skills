# Public FAQ

## Is this just a prompt library?

No. A prompt asks for an answer. A skill defines a repeatable workflow, inputs, output shape, decision boundary, quality bar, failure modes, references, and evals.

## Can agents use these skills to manage people?

No. The skills help prepare leadership work. Human leaders own sensitive decisions, communication, accountability, and consequences.

## Are examples based on real companies?

No. Public examples are synthetic. Do not contribute private company, employee, customer, or meeting data.

## Which skill should I try first?

Start with `decision-memo` if you have an ambiguous decision, or `weekly-leadership-pack` if you want a recurring operating brief.

## Why include AI-native management skills?

Because leaders are starting to manage work done by humans and agents together. That creates new management jobs: delegation briefs, output review, command centers, eval design, memory operations, risk governance, and improvement backlogs.
