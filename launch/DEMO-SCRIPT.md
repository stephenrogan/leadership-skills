# Demo Script

## Setup

Use the `decision-memo` example.

Messy input:

> The enterprise team is split on whether to move named CSM coverage into a pooled model for sub-500k ARR accounts. Finance wants capacity relief. Sales is worried about renewal risk. CS leaders think named ownership is inconsistent anyway.

## Beat 1: show the weak baseline

A generic prompt gives advice: weigh pros and cons, consider customer impact, think about risk.

That is not enough. It leaves the leader with the same work they had before.

## Beat 2: show the skill output

The skill creates:

- decision owner
- deadline
- options table
- upside/downside/reversibility
- missing context
- dissent to preserve
- recommendation
- human approval boundary
- revisit trigger

## Beat 3: name the difference

The improvement is not writing quality. It is operating quality.

The skill reduces decision drift, preserves uncertainty, and makes the next human decision explicit.
