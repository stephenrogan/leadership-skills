# Launch Kit

This repo should not be made public with only code changes. Use this kit to launch it as a serious public asset.

## Positioning

Agent Skills for leaders managing humans, agents, workflows, memory, and governance.

## Announcement draft

I put together a public library of Agent Skills for leadership work.

Not prompts for "being a better manager."

More like operating templates for the work around leadership:

- decision memos
- 1:1 prep
- stakeholder prewires
- weekly leadership packs
- agent command centers
- agent risk governance

The agent prepares the packet.
The human still owns the decision.

That boundary matters more as teams start managing humans and AI agents in the same operating system.

## Short demo script

1. Open with a messy leadership input: unclear decision, conflicting stakeholders, thin evidence.
2. Show the generic prompt baseline: plausible but too vague to use.
3. Run the relevant skill.
4. Show the artifact: owner, evidence, assumptions, options, boundary, follow-up.
5. Close with the operating rule: agents should prepare leadership work, not pretend to own leadership judgment.
